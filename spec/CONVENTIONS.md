# Skill 设计规范

## 文件组织

- 每个 skill 是一个目录，目录名即 skill 标识符
- 目录内必须包含 `SKILL.md`
- 附属资源（示例、模板等）可放在同目录下

## SKILL.md 格式

```markdown
---
name: skill-name
description: 一句话说明用途和触发场景
---

# 标题

## 目标
这个 skill 要达成什么结果

## 适用场景
- 场景1
- 场景2

## 执行步骤
1. 步骤一
2. 步骤二

## 验证标准
- [ ] 检查项1
- [ ] 检查项2

## 反模式（可选）
| 借口 | 回应 |
|------|------|
| "常见错误说法" | "正确做法" |

## 示例（可选）
```

## 设计原则

1. **通用性**：不绑定特定平台或工具
2. **最小必要**：只包含 AI 执行所需的信息
3. **可验证**：每个 skill 应有明确的完成标准
4. **自然语言指令**：不依赖特定 API 或格式

## 分类约定

| 目录 | 内容 |
|------|------|
| `skills/` | 可直接加载执行的工作流 skill |
| `references/` | 通用规范、准则、笔记（非 skill，通常手动复制使用） |
