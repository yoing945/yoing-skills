# 项目级 AGENTS.md 规范

本文件供 `agents-guide` skill 在处理项目级指南时读取。

## 文件定位

- 文件名：`AGENTS.md`
- 位置：项目根目录

## 默认三节

### 1. 项目概述

一句话描述项目是什么、解决什么问题。

### 2. 文档索引

列出项目中真实存在的文档。表格严格分两列：

| 文档 | 说明 |
|------|------|

索引范围：

- 只索引根目录及子模块概览文档
- 不深入子模块内部
- 禁止虚构不存在的文件

### 3. 项目结构

顶层目录树 + 每个目录一句话职责。

格式示例：

```
yoing-skills/
├── .agents/    # 项目级 AI 助手数据
├── skills/     # 核心 skill
└── prompts/    # AI 行为与编码提示词
```

## 模块级内容处理

子模块特有的规范、依赖、注意事项留给模块级指南，不要写入项目级 AGENTS.md。
