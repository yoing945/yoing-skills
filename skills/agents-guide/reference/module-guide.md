# 模块级 AGENTS.md 规范

本文件供 `agents-guide` skill 在处理模块级指南时读取。

## 与项目级指南的关系

遵循项目级 `AGENTS.md` 的导航文档规范，仅补充模块级差异。不重复项目级已覆盖的全局内容。

## 文件定位

- 文件名：模块目录下的 `.md` 文件
  - 默认建议为 `<模块名大写>.md`，如模块目录为 `payment/`，默认文件名为 `PAYMENT.md`
  - 用户可指定其他 `.md` 文件名
- 位置：对应模块目录下

## 父级模块文档更新

生成或更新模块级指南后，必须向上查找并更新父级模块文档的索引。

### 查找规则

从当前模块目录的父目录开始，逐层向上查找父级模块指南文件：

1. 优先查找默认命名的 `<父目录名大写>.md`
2. 若不存在，查找父目录下其他可能的模块指南 `.md` 文件
3. 若存在多个或无法确定，向用户确认应更新哪个文件
4. 若未找到，停止查找，向用户说明

示例：当前模块为 `src/services/payment/`，默认规则下：

1. 在 `src/services/` 优先查找 `SERVICES.md`
2. 若未找到，查找 `src/services/` 下其他可能的模块指南 `.md`
3. 若仍未找到，继续向上到 `src/` 重复上述过程
4. 若到项目根目录仍未找到，停止

### 更新规则

找到父级模块文档后：

1. 在其文档索引表格中添加当前模块条目：
   ```markdown
   | [PAYMENT.md](payment/PAYMENT.md) | 支付核心模块 |
   ```
2. 向用户展示父级文档的 diff
3. 经用户确认后更新父级文档

### 边界情况

- 若父级模块文档不存在，不自动创建
- 若父级文档索引中已存在当前模块条目，不重复添加
- 若当前模块位于项目根目录的直接子目录下，父级为项目级 `AGENTS.md`，按同样规则更新其文档索引

## 默认三节

### 1. 模块概述

一句话描述模块在项目中的职责边界。

### 2. 文档索引

列出本模块及子目录中真实存在的文档。表格严格分两列：

| 文档 | 说明 |
|------|------|

索引范围：

- 只索引本模块及子模块概览文档
- 不深入子模块内部
- 禁止虚构不存在的文件
- 不跨层引用父目录或根目录文档
- 仅可列出直接上层模块的模块指南 `.md` 文件作为父上下文入口

### 3. 模块结构

模块内顶层目录树 + 每个目录一句话职责。

格式示例：

```
payment/
├── api/        # 对外接口
├── core/       # 核心逻辑
└── tests/      # 模块测试
```
