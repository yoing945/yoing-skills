# AI 助手指南生成

生成项目级或模块级的导航文档。

> **硬性规则**：除非用户明确要求，否则指南只包含三节：概述、文档索引、结构。禁止默认写入技术栈、架构、编码规范、测试、依赖、注意事项等章节。

## 触发条件

- 用户明确调用 `agents-guide`
- 用户要求创建或更新：
  - 根目录的 `AGENTS.md` → 项目级
  - 模块目录下的 `.md` 导航文档 → 模块级（默认文件名为 `<模块名大写>.md`，用户可指定其他名称）

## 检查清单

你必须按顺序完成以下步骤：

1. **确认级别和文件名** — 项目级（`AGENTS.md`）或模块级（默认 `<模块名大写>.md`，用户可指定其他 .md 文件名）
2. **检查现有文件** — 若已存在，读取当前内容并准备 diff
3. **读取对应规范** — 项目级读取 `reference/project-guide.md`，模块级读取 `reference/module-guide.md`
4. **生成默认三节** — 概述、文档索引、结构
5. **处理可选章节** — 仅在用户明确要求时添加
6. **自检** — 按下方自检清单检查生成内容
7. **展示结果** — 向用户展示生成的内容或 diff
8. **等待用户确认** — 在用户批准前不要写入文件
9. **写入文件** — 用户确认后写入指定路径。若是模块级，按 `reference/module-guide.md` 处理父级模块文档更新。

> **终止状态**：用户确认后的指南文件写入完成。不要在此 skill 中进入实现、代码生成或其他 skill 调用。

## 自检

展示结果前，必须按以下清单自检。发现问题直接修复，无需重新向用户展示中间过程。

- [ ] **章节检查**：默认只有概述、文档索引、结构三节（用户明确要求补充的除外）
- [ ] **文档索引格式**：表格严格两列，文档列为 `[xx.md](dir/xx.md)`，说明列为一句话
- [ ] **项目结构格式**：缩进目录树，每个目录后加 `# 一句话职责`
- [ ] **真实性检查**：文档索引中引用的文件真实存在
- [ ] **禁止内容检查**：无类设计、流程步骤、详细架构表格、源码级详细逻辑
- [ ] **重复项检查**：文档索引中无重复条目
- [ ] **模块级特有检查**（仅模块级）：
  - 文件名是否为 `.md` 文件（默认建议 `<模块名大写>.md`，但允许用户指定）
  - 是否未重复项目级 `AGENTS.md` 已覆盖的全局内容

## 项目级与模块级差异

| 维度 | 项目级 | 模块级 |
|------|--------|--------|
| 文件名 | `AGENTS.md` | 默认 `<模块名大写>.md`，用户可指定其他 .md 文件名 |
| 位置 | 项目根目录 | 模块目录 |
| 默认三节 | 项目概述、文档索引、项目结构 | 模块概述、文档索引、模块结构 |
| 引用范围 | 根目录及子模块概览 | 本模块及子目录 |
| 跨层引用 | 不跨层 | 仅可列出直接上层模块的模块指南 `.md` 文件 |

## 通用格式要求

### 文档索引

表格严格分两列：

| 文档 | 说明 |
|------|------|

- **文档列**：`[xx.md](dir/xx.md)`，相对路径链接
- **说明列**：一句话描述该文档的作用

### 结构

格式：缩进目录树，每个目录后加 `# 一句话职责`。

示例：

```
project/
├── src/          # 业务源码
├── tests/        # 测试用例
└── docs/         # 项目文档
```

禁止写入：

- 子目录内的逐文件清单
- 类名、函数签名
- 频繁变动的实现细节

## 仅在用户明确要求时补充

- 技术栈与运行
- 架构速查
- 编码规范
- 测试与验证
- 依赖与禁忌
- 注意事项

## 禁止写入指南

- 类设计、流程步骤、详细架构表格
- 源码已表达的详细代码逻辑
