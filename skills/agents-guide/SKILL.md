# AI 助手指南生成

为任意目标目录生成导航文档。

> **硬性规则**：除非用户明确要求，否则指南只包含三节：概述、文档索引、结构。禁止默认写入技术栈、架构、编码规范、测试、依赖、注意事项等章节。

## 命令接口

```text
agents-guide [path]
```

- 不带 `path`：目标目录为项目根，生成 `AGENTS.md`
- 带 `path`：目标目录为指定路径，生成 `<目录名大写>.md`

示例：

```text
agents-guide              # 生成 AGENTS.md
agents-guide src/payment  # 生成 src/payment/PAYMENT.md
```

## 文件名规则

| 目标目录 | 文件名 | 位置 |
|---|---|---|
| 项目根 | `AGENTS.md` | 项目根目录 |
| 非根目录 | `<目录名大写>.md` | 目标目录下 |

目录名大写规则：取目标目录最后一级目录名并转为大写。

## 触发条件

- 用户明确调用 `agents-guide`
- 用户要求创建或更新某个目录的 AI 助手指南文件

## 检查清单

你必须按顺序完成以下步骤：

1. **确认目标目录** — 不带 `path` 时为项目根；带 `path` 时为指定目录
2. **检查现有文件** — 若目标目录下已存在指南文件，读取当前内容并准备 diff
3. **生成默认三节** — 按下方要求生成概述、文档索引、结构
4. **处理可选章节** — 仅在用户明确要求时添加
5. **自检** — 按下方自检清单检查生成内容
6. **展示结果** — 向用户展示生成的内容或 diff
7. **等待用户确认** — 在用户批准前不要写入文件
8. **写入文件** — 用户确认后写入指定路径
9. **父级索引回写** — 若目标目录不是项目根，按下方规则向上查找父级指南文档并更新索引

> **终止状态**：用户确认后的指南文件写入完成，且父级索引回写处理完毕。不要在此 skill 中进入实现、代码生成或其他 skill 调用。

## 自检

展示结果前，必须按以下清单自检。发现问题直接修复，无需重新向用户展示中间过程。

- [ ] **章节检查**：默认只有概述、文档索引、结构三节（用户明确要求补充的除外）
- [ ] **概述检查**：不重复目录名，不写空泛描述
- [ ] **文档索引格式**：表格严格两列；只含 `.md` 文件；不含当前指南文件、`README.md`、隐藏目录文件；文档列 `[文件名](相对路径)` 不带 `.md` 后缀；说明列使用"说明/记录/定义/整理/描述 + 具体内容"句式
- [ ] **结构格式**：只含直接子目录，不含任何文件和隐藏目录；每个目录后加 `# 动词 + 具体内容`，动词限定为 存放/提供/承载/组织/管理
- [ ] **真实性检查**：文档索引中引用的文件真实存在
- [ ] **禁止内容检查**：无类设计、流程步骤、详细架构表格、源码级详细逻辑
- [ ] **重复项检查**：文档索引中无重复条目
- [ ] **父级回写检查**（非根目录）：父级指南文档索引中已正确添加当前目录条目，未重复添加

## 默认三节

### 1. 概述

一句话描述该目录是什么、解决什么问题或承担什么职责。

### 2. 文档索引

列出目标目录及直接子目录中真实存在的 `.md` 文档。表格严格分两列：

| 文档 | 说明 |
|---|---|

索引范围与排除项：

- 只索引目标目录及直接子目录下的 `.md` 文件
- 不深入更下层目录
- 不索引当前正在生成的指南文件本身
- 不索引 `README.md`
- 不索引隐藏目录（以 `.` 开头）下的文件
- 禁止虚构不存在的文件

格式规则：

- **文档列**：`[文件名（不含 .md）](相对路径)`，相对路径从目标目录出发
- **说明列**：使用"说明/记录/定义/整理/描述 + 具体内容"的句式，一句话

示例：

```markdown
| [AGENTS_LOCAL](AGENTS_LOCAL.md) | 说明 .agents/ 目录的职责、结构与注意事项 |
| [MEMORY](memory/MEMORY.md) | 记录项目级记忆文件索引 |
```

### 3. 结构

目标目录内的直接子目录树，每个子目录后加 `# 一句话职责`。

范围与排除项：

- 只列出目标目录下的直接子目录
- 不列出任何文件（包括当前指南文件、README、配置文件等）
- 不列出隐藏目录（以 `.` 开头）

职责描述规则：

- 使用动词 + 具体内容，限定动词池：存放、提供、承载、组织、管理
- 一句话，不含实现细节

格式示例：

```text
project/
├── src/          # 存放业务源码
├── tests/        # 存放测试用例
└── docs/         # 存放项目文档
```

## 父级索引回写

在非根目标目录生成或更新指南后，自动向上查找父级指南文档并更新其索引：

1. 从目标目录的父目录开始
2. 优先查找 `<父目录名大写>.md`
3. 若不存在，查找父目录下其他可能的 `.md` 指南文件
4. 若找到，在其文档索引表格中添加当前目标目录条目
5. 若父目录为项目根，则更新 `AGENTS.md`
6. 若未找到父级指南文档，停止查找并向用户说明

边界情况：

- 若父级指南文档不存在，不自动创建
- 若父级文档索引中已存在当前目录条目，不重复添加

## 仅在用户明确要求时补充

- 技术栈与运行
- 架构速查
- 编码规范
- 测试与验证
- 依赖与禁忌
- 注意事项

## 禁止写入指南

- 类设计、流程步骤、详细架构表格
- 源码已表达的详细代码逻辑
