# 项目上下文获取

快速了解当前项目的架构、规范、记忆和约束，为后续工作建立上下文基础。

## 触发场景

- 用户首次在当前项目中发起对话
- 用户明确要求了解项目架构、规范或上下文
- 用户问"这个项目是什么"、"项目结构是怎样的"等类似问题
- 当前任务需要基于项目特定约定执行

## 执行步骤

### 步骤1：读取项目指南文件

按优先级查找并阅读项目指南：`AGENTS.md` → `README.md` → 概览项目目录结构。

### 步骤1.5：加载关联项目上下文（可选）

如果在步骤1中读取到的 `AGENTS.md` 包含"关联项目"章节：

1. 查找当前目录下的 `.agent.context*.md` 文件，优先级：`.agent.context.local.md` > `.agent.context.md`
2. 若存在，解析其中的关联项目名称及本地路径
3. 向用户展示关联项目列表，询问需要加载哪些（全部 / 部分 / 不加载）
4. 仅对用户确认的项目并行启动子 agent，执行简化版上下文获取（只读指南文件，不深入源码，不读记忆文件）

若 AGENTS.md 中无"关联项目"章节且 `.agent.context*.md` 不存在，跳过此步骤。

### 步骤2：读取项目记忆文件

查找并阅读项目级记忆文件（这些文件通常包含用户偏好、项目约定和历史上下文）：

1. 查找 `.agents/` 目录下 `memory/` 子目录中的内容；以及该目录 `AGENTS.md`
2. 若记忆文件过多，优先读取最新修改的文件；若内容过长，优先读取摘要性内容

### 步骤3：整合上下文并输出摘要

基于以上读取到的信息，向用户输出一份简洁的项目上下文摘要，包含：

- **项目概述**：一句话描述项目是什么
- **技术栈**（如有）：主要语言、框架、工具
- **关键规范**：编码风格、目录约定、命名规则等
- **项目结构**：顶层目录及其职责
- **记忆要点**：用户的特殊偏好、历史决策、注意事项
- **文档索引**：项目中值得参考的重要文件列表
- **关联项目上下文**（如有）：已加载的关联项目名称、路径及其核心上下文摘要

输出应精炼、无冗余，只提供 AI 执行后续任务所需的必要上下文，不展开详细设计。信息量大时（超过10000TOKEN）分段条理概括呈现。

## 验证标准

- [ ] 已尝试读取根目录的 `AGENTS.md` 或 `README.md`
- [ ] 若 AGENTS.md 包含关联项目，已向用户确认需要加载的项目，并仅加载用户指定的项目（或已跳过）
- [ ] 已检查 `.agents/` 下的记忆文件
- [ ] 向用户提供了整合后的上下文摘要（含关联项目，如有）
