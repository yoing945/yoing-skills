# 项目/模块上下文获取

根据输入自动判断目标范围：无参数时获取项目级上下文，带模块名或路径时获取模块级上下文，为后续开发或修改建立精确上下文。

## 触发场景

- 用户首次在当前项目中发起对话
- 用户要求了解项目架构、规范或上下文
- 用户要求了解某个具体模块的实现细节
- 当前任务涉及对特定模块的代码修改
- 用户问"这个项目是什么"、"xxx 模块是怎么实现的"等

## 命令接口

```text
agents-context [target]
```

- **无 `target`**：生成项目级上下文（等价于原 `project-context`）。
- **`target` 是路径**（如 `skills/agents-guide`）：生成该目录的模块级上下文。
- **`target` 是名称**（如 `agents-guide`）：先读取当前目录 `AGENTS.md` 的 `## 文档导航` 匹配 `name`，匹配失败再按目录名搜索。

## 模式推断流程

```text
target 为空？
  → project 模式
target 是存在路径？
  → module 模式（按路径）
否则
  读取当前目录 AGENTS.md 的 ## 文档导航
  查找 name 或文件名匹配 target 的条目
  找到 guide 条目？
    → module 模式（按该 guide 的路径）
  未找到？
    → 按目录名搜索；仍无结果则报错或询问用户
```

## 公共步骤

两种模式共享以下步骤：

### 步骤 1：读取项目指南文件

按优先级查找并阅读项目指南：`AGENTS.md` → `README.md` → 概览项目目录结构。

### 步骤 2：读取项目记忆文件

查找并阅读项目级记忆文件：

1. 查找 `.agents/` 目录下 `memory/` 子目录中的内容；以及该目录 `AGENTS.md`
2. 若记忆文件过多，优先读取最新修改的文件；若内容过长，优先读取摘要性内容

### 步骤 3：加载上下文文件（可选）

查找 `.agent.context*.md` 文件，优先级：`.agent.context.local.md` > `.agent.context.md`。

- project 模式：将其中的条目作为"关联项目"处理。
- module 模式：将其中的条目作为"模块依赖"处理。

若文件不存在，跳过此步骤。

## project 模式执行流程

1. 执行公共步骤 1-2。
2. 执行公共步骤 3（作为关联项目）。
3. 若存在关联项目，向用户展示列表，询问需要加载哪些（全部 / 部分 / 不加载）。
4. 仅对用户确认的项目并行启动子 agent，执行简化版上下文获取（只读指南文件，不深入源码，不读记忆文件）。
5. 整合输出项目级上下文摘要：
   - **项目概述**：一句话描述项目是什么
   - **技术栈**（如有）：主要语言、框架、工具
   - **关键规范**：编码风格、目录约定、命名规则等
   - **项目结构**：顶层目录及其职责
   - **关联项目上下文**（如有）：已加载的关联项目名称、路径及其核心上下文摘要

输出应精炼、无冗余，只提供 AI 执行后续任务所需的必要上下文。

## module 模式执行流程

1. 执行公共步骤 1-2（用于输出"项目上下文摘要"）。
2. 通过模式推断定位模块目录。
3. **阅读模块文档**：如果模块根目录存在 `.md` 文档（如 `<模块名>.md`、`README.md` 等），优先阅读。
4. **阅读源码**：浏览模块内的核心源码文件（入口文件、主要逻辑文件、对外接口文件），了解模块的职责边界、关键类/函数和实现逻辑，优先阅读摘要性内容和核心接口，不陷入实现细节。
5. 执行公共步骤 3（作为模块依赖）。
6. 若存在依赖，向用户展示列表，询问需要加载哪些（全部 / 部分 / 不加载）。
7. 仅对用户确认的依赖并行启动subagent，执行简化版上下文获取（只读指南文件和模块文档，不深入源码，不读记忆文件）。
8. 整合输出模块上下文摘要：
   - **模块定位**：该模块在项目中的位置和职责边界
   - **项目上下文摘要**：基于公共步骤的项目级关键信息
   - **模块文档要点**：模块文档中的关键约定和结构
   - **源码关键信息**：核心类/函数、入口点、关键逻辑概述
   - **依赖上下文**（如有）：已加载的依赖模块/项目的核心信息
   - **注意事项**：模块的特殊约定、已知坑点

输出应精炼、无冗余，聚焦模块本身。

## 验证标准

- [ ] 已根据输入正确推断 project 或 module 模式
- [ ] 已读取项目级指南和记忆文件
- [ ] project 模式下，若存在关联项目，已向用户确认并仅加载指定项目（或已跳过）
- [ ] module 模式下，已确定并定位目标模块
- [ ] module 模式下，已阅读模块文档和核心源码
- [ ] module 模式下，若存在依赖，已向用户确认并仅加载指定依赖（或已跳过）
- [ ] 向用户提供了对应模式的上下文摘要
