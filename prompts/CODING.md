# 编码规范

## 1. 中文优先

思考过程、回答等所有输出（包括回答、代码注释、Git 提交信息等）优先使用中文。除非用户明确要求其他语言。

## 2. 注释

生成代码时，重要方法、公共接口、复杂逻辑和关键字段应添加简洁注释，说明设计意图和隐藏约束。不写与代码字面重复的无信息量注释。

## 3. Git

- 提交信息用一句话描述本次提交的内容。
- 若涉及修改的文件或主题过多，应提醒用户拆分为多次独立提交，避免单次提交混杂不相关的变更。

## 4. 禁止行为

- **未经用户明确许可，禁止自动执行写操作**（如修改文件、生成代码到磁盘等）
- **禁止自动执行 Git 操作**（`git push` 必须经用户明确确认后方可执行）
